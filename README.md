## 👨‍💻 About This Project

**Rahul Kasta – Personal Portfolio** is a modern and responsive developer portfolio website created to showcase my professional profile, technical skills, educational background, and development journey.

The website features a clean dark interface, interactive elements, smooth animations, and a modern 3D-inspired visual experience.

It represents my learning journey, technical interests, and passion for building modern web applications.

## ✨ Key Features

- Modern homepage with animated introduction.
- About section presenting my background and goals.
- Skills section showcasing technical knowledge.
- Education section displaying academic qualifications and training.
- Projects section to showcase development work.
- Contact section with professional contact information.
- Fully responsive design for desktop, tablet, and mobile.
- Interactive navigation and smooth page transitions.
- CSS-based 3D-inspired effects and animations.
- Downloadable resume.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Component-based UI development |
| JavaScript | Interactive functionality |
| Tailwind CSS | Utility-based styling |
| CSS3 | Custom styling and animations |
| React Router | Page navigation |
| Framer Motion | Animations and transitions |
| React Icons | Interface icons |
| Vite | Development server and build tool |

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/git-kasta2003/rahul-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd rahul-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Build for production**

```bash
npm run build
```
